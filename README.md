# CalculatoryApp
CalculatoryApp

## Download & Install

Get the latest installer from the [Releases page](https://github.com/369-Lottery/CalculatorApp/releases/latest).

### Windows SmartScreen warning

The installer isn't code-signed yet, so Windows will show a **"Windows protected your PC"** warning the first time you run it. This is expected — to proceed:

1. On the SmartScreen screen, click **More info**
2. Click **Run anyway**

If your browser also blocks the download itself (e.g. "This file isn't commonly downloaded"), click **Keep** / **Keep anyway** on the download bar.
